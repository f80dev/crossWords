## Génération du frontend

generer une application angular se nommant CrossWordsApp en utilisant angular material et les dernière technique de programmation comme Signal
Cette application permet de fabriquer des grilles de mots croisée en appellant une API
Cette application n'affiche qu'un seul écran permettant de 
- charger un fichier pdf ou epub
- régler un age (entre 5 et 80)
- fixer une taille de grille
- appeller l'api generate_crossword en passant le fichier, un age et une taille de grille
elle appel l'API avec ces paramétre et récupére un fichier PDF contenant la grille et les définitions
